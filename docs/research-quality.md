# 研究输出质量

[English](research-quality_EN.md)

## 交易价位

普通单股分析与 Agent 报告共用价位校验，持久化历史记录和生成 DecisionSignal 时也执行同一规则。多头场景要求止损低于入场、目标高于入场；主买点和次买点分别检查。主计划有效、但替代买点未匹配有效止损/目标时，只撤下替代买点并提示它需要独立计划，保留主计划。无法解析的价格保持缺失，NaN、无穷、负值和布尔值不作为价格。明确“暂无买点”的文字不会把后面的均线观察价提取成入场价。

发现矛盾时，`dashboard.battle_plan.price_validation.status=invalid`，清空四个 sniper_points，替换冲突的执行计划并附警告。后续提取器不再从原始模型响应恢复这些价位。买入/加仓动作降为观望；已有持仓的卖出/减仓意图不强行改成买入或观望。原始模型文本仅用于审计，不能作为有效交易指令。

价位齐全且顺序一致时，`price_validation.risk_reward_ratio` 使用 `(take_profit - ideal_buy) / (ideal_buy - stop_loss)` 计算；`entry_basis=ideal_buy`。目标价字段中的模型自述盈亏比会移除。它只校验价位场景，不表示条件已触发、能成交或包含手续费；`execution_authorized` 始终为 false。缺失项状态为 incomplete，不制造入场价或止损价。不追溯改写已有历史记录。

这是现有自由文本价位契约上的保守检查，不是任意自然语言交易计划的完整证明。复杂区间、盘中/收盘条件仍需结构化策略执行器验证，不能把研究散文直接当委托参数。

## 证据与缺失数据

普通分析、单 Agent 和决策 Agent 的生成指令要求区分事实、推论、缺失项和持仓前提。没有提供历史估值分位或可比公司数据时，不允许声称“相对历史便宜/昂贵”；未取得有效新闻不代表没有利空。

普通流水线确认新闻条数为零时，会将新闻摘要、仪表盘新闻结论及相关新闻检查项改成“风险未完成排查”，并追加风险提示。条数未知时不擅自覆盖已有内容。Agent 路径通过共用证据指令约束，不能声称已对任意生成文字做完整事实核验。新增校验警告覆盖简体中文、繁体中文、英文、日文和韩文。

## 历史日期与选股

`DatabaseManager.get_analysis_context(code, target_date)` 只读取日期不晚于目标日的最近两根日线。非交易日使用之前的数据；没有符合条件的数据返回 None。它不会自动把新闻、实时行情等其他数据变成历史快照，整份历史回放仍需固定全部输入。

选股默认严格 Top-N；显式 `variant_seed` 才启用近分候选轮换。相同排序输入、版本和种子可复现，运行 ID 和当前日期不再参与扰动。模型随机性和行情变化不在此保证范围内。

选股风险等级新增 `unknown`：扣分本来较低、但日线质量/LLM 风险信息/行业信息不完整时使用。中高风险保留，缺失项记入 risk_flags；因子分数与风险否决阈值不变。客户端应把 unknown 视为未充分评估，而非 low。

## 验证与范围

回归覆盖实际出现的入场价等于止损价、错误盈亏比、无买点文字、原始响应回填、决策信号降级、五语言警告、目标日之后的行情、同 seed 不同 run_id 和缺失风险数据。

本轮不改模型额度/计费、会员调用预算或真实交易渠道，不承诺全链路超时和长期收益改善。模型调用截止时间、会员身份在线对照及更大样本评估需独立验证后再调整。
