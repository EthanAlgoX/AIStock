# 策略验证与运行

`/trading` 先配置和保存策略规则，不选择回测／模拟模式。保存只写入私有策略定义，不创建验证账户、任务或订单。保存后选择“历史回测”“运行一次”“持续模拟”，补充验证资金（回测另需日期区间），确认后创建独立验证账户并启动。策略下的验证记录可切换查看，已有模拟可继续运行或暂停。每次新验证独立记账，不覆盖旧结果；修改规则通过复制策略保存新定义。

旧账户位于“已有独立验证记录”，原 `portfolio` 链接可继续访问；可复制旧配置保存为策略后开始新的验证。旧研究提案保留在 `/trading?view=reports`，原 `run`、`sourceRun` 链接继续兼容；研究提案不会自动成为交易指令。

## 规则与运行

首版提供量价突破、趋势回踩、低波动动量三个确定性日线模板，复用历史验证评分逻辑。低波动动量不是基本面质量策略。股票池可填写名称、别名、拼音或代码，复用个股研究目录展示识别结果；多匹配时选择候选。市场与计价币种自动识别，识别后的代码去重后，每个账户使用同市场的 1–12 个固定股票代码；支持 A 股、美股和港股，分别以 CNY、USD、HKD 记账。港股每手数量需要用户核对；A 股首版限每手 100 股的普通股票或 ETF。

回测最多两年；持续模拟从验证账户创建当天的市场当地日期开始。两种方式使用相同规则与费用模型，但独立账户、日期区间和净值账本。详情可复制配置、创建同配置的另一种验证，并对照观察区间、样本数和表现。配置保存后不修改，调整规则复制并保存新策略，避免覆盖旧结果。

每个已收盘交易日：先以当日开盘价及配置滑点执行上一记账日的意图，再按收盘价估值、形成下一交易日的观点。首日仅形成观点；仍被选中的已有持仓保留，退出者卖出，新入选者按现金、整手和建仓上限买入。建仓比例不保证后续涨跌后的仓位一直低于该比例。未成交也记录原因。

持续运行通过现有工作区调度器检查交易日历，收盘至少 20 分钟后尝试取得完整日线。没有新的已收盘交易日时不重复创建任务。服务恢复时补记的较早日期标注为历史回放，不作为当时在线决策的证明。暂停自动买卖后仍保留持仓并估值；手动“运行一次”会执行下一次可用的日线步骤。这里的持续模拟不是盘中实时行情或高频撮合。

## 页面与指标

详情包括八项指标、累计收益与基准曲线、每日收益柱图，以及按日期查看的买卖和逐股观点、最新持仓。观点覆盖股票池每个成员，标注看好／看淡／中性、持仓状态、价格规则依据；成交保留实际使用的前一日观点和信号日期。规则观点不调用或冒充专家模型。

- 累计收益：最新净值 / 初始资金 − 1；当日收益：最近估值日相对上一净值的变化，首日以初始资金为基数。
- 年化收益：按 252 个交易日复利折算；年化波动率：日收益样本标准差 × √252。
- 最大回撤：净值相对此前最高净值的最大跌幅，包含初始资金这个起点。
- 区间换手率：区间买卖成交额之和 / 2 / 区间平均日净资产，不是年化换手率。
- 夏普：日均超额收益 / 日收益样本标准差 × √252，无风险利率按配置换算为日利率。
- 卡玛：年化收益 / 最大回撤。

年化指标至少需要 20 个记账交易日；零波动时夏普、零回撤时卡玛显示“—”。缺失不显示为零。基准使用沪深 300 ETF（510300）、标普 500 ETF（SPY）或恒生指数 ETF（02800）的价格代理，存在跟踪误差，不代表指数总回报。图表可以切换系列、查看数值表、导出 SVG。

指标概念参考 [QuantConnect glossary](https://www.quantconnect.com/docs/v2/writing-algorithms/key-concepts/glossary)，具体实现以本文口径为准。

## 数据、任务与隔离

API：`GET/POST /api/v1/simulation/portfolios`、`GET /templates`、`GET /{id}`、`POST /{id}/control`（`run/start/pause`）。创建仅接受固定模板及数值配置，不接受代码。普通注册用户与管理员各自使用原有私有数据库，账户、成交和任务不跨用户可见；后台线程继承用户作用域，并重新核对账号是否启用。

新表 `simulation_portfolio_runs` 保存账户配置、运行状态、租约和已记账日期；复用原模拟账户、策略版本、运行、订单、成交、持仓、净值表。每个交易日原子保存，重复点击和任务重试不会重复成交。保存输入日线、数据源、记录时间、信号原因，便于复盘。单进程 Web 启动时恢复中断租约，保留已完成日期。暂不支持多进程共用同一调度数据库。

每次检查进入“任务与运行”，成功、失败均留档，任务详情可返回策略账户。价格缺失、重复日期、基准交易日不完整会停止记账并展示错误，已有日期保留。固定规则不调用 LLM，不产生模型 Token；后续单独发起专家研究仍按原功能记账。

## 验证边界与部署

采用数据源提供的日线口径，简化撮合不模拟盘口、部分成交、涨跌停排队、分红或拆股持仓调整。固定股票池存在选择偏差；日线可能包含数据源复权处理。不得将跨除权事件的表现当成已完成企业行动校验的真实收益。应核对数据源、股票池、交易成本与观察周期后再比较策略。

无需新增环境变量。数据库初始化自动创建新表，旧表字段不变；旧模拟运行响应的 `execution_mode` 新增 `portfolio_day`，旧创建请求仍保持原契约。部署保留现有环境、挂载与 SSH 授权，备份数据库和容器。回滚至上一个镜像即可，新表和新增记录保留但旧界面不展示；恢复新版后可以继续查看。不要在策略或其他任务正在执行时切换容器。

创建失败时保留表单与服务器错误原因；后台刷新不清除创建错误。股票池支持逗号、顿号、分号和空白分隔，去重后需为 1–12 个代码。

Web 在创建前将名称解析为规范代码，API 仍接收原有代码与市场字段。无名称记录的代码会提示核对；无法识别的名称或混合市场不会提交。切换到新市场时使用对应默认手数（美股 1，A 股／港股 100），港股仍需在高级配置核对实际每手数量。

股票目录接口同时使用项目共享名称映射补充中文别名（例如 NVIDIA 的“英伟达”），保留数据源原名与原始索引文件；个股研究与交易使用同一份增强后的目录。

股票目录通过 gzip 压缩传输，客户端最多等待 60 秒；加载失败时保留输入，可点击“重新加载股票目录”恢复名称识别。压缩仅作用于公共目录，不改变流式报告或私有 API。

### 策略与验证契约

`GET/POST /api/v1/simulation/portfolios/definitions` 列出／保存策略；保存请求拒绝 `mode`、`startDate`、`endDate`。`POST /definitions/{id}/validations` 接收模式、验证资金和日期，创建待运行账户；前端随后调用现有 `/control` 启动。若启动失败，已创建记录保留，可在记录中重试。返回账户新增可空 `definitionId`，旧直接创建接口保持兼容。各用户（含管理员）复用原私有数据库隔离。

新增 `simulation_portfolio_definitions` 表由数据库初始化建立，旧表字段不变；验证配置保存所属定义 ID 快照。回滚旧镜像保留新表与账户数据，旧客户端仍能读取账户，恢复新版后可再次按策略分组。

策略顶部的单次与持续模拟优先继续最近的同策略模拟账户；仅首次模拟补充资金并创建账户，切换运行方式不重置持仓或净值。

## Agent 策略与范围

新策略默认使用 Agent，选择已启用的 Skill，并保存其内容、版本摘要和自定义交易指令。原有三个固定规则仍可选择。配置阶段只保存策略，随后选择运行一次、持续模拟或历史验证；修改 Skill 或指令应复制为新策略。交易模型实际名称随首个决策冻结，后续模型名称变化会停止验证。

范围支持指定股票、选择私人持仓账户中的股票，以及自然语言行业/概念、20 日波动率条件。范围必须先预览，展示解析条件、候选、来源与时间，才能保存。自定义范围复用现有选股源，在其最多 50 个候选中筛选，不代表全市场行业成分股；可额外指定股票作为交集限制。未找到匹配时明确报错，不扩大范围。持仓范围只引用股票名单，不导入真实账户资金、成本或交易。范围可以固定，或按日/周刷新；刷新后离开候选的旧持仓仍会估值并可减仓、退出，禁止增仓。

Agent 当前证据包含截至决策日的最近 21 根日线、模拟账户、候选范围和约束，不自动提供新闻与财报工具。Skill 所需证据不足时应说明缺口并保持仓位。模型输出逐股目标仓位和理由，程序校验股票覆盖、仓位总和、单股上限及持仓数量，再通过原账本于下一交易日开盘模拟成交，支持加减仓。没有交易也会记录观点。模型失败或输出不合法不会写入当日账本。

每次执行最多处理 20 个交易日，并受独立 Token 预算约束；输入预算不足时调用前停止。原有用户每日限额继续生效。范围解析也消耗 Token；决策详情记录模型、实际 Token、完整可见输入与回答，校验失败也保留调用记录。账户页面展示最近 20 次调用，全部记录保留在各用户私有数据库的 `simulation_trading_calls`；范围快照存于 `simulation_universe_snapshots`，包含管理员自己的使用。

Agent 历史验证明确标注为“AI 历史回放”，不能消除模型预训练知识带来的未来信息风险。固定名单回放存在选股偏差；历史范围模式只使用此前实际保存的当日快照，缺少快照就停止。持续模拟补漏日期只估值并执行此前已有计划，不事后生成过去的 AI 买卖决策。此模式仍为每日模拟，并非盘中实时交易或券商下单。

新增表为追加兼容，旧规则及账户继续运行。部署前备份数据；回滚旧镜像时应同时恢复部署前数据库备份，避免旧版本误执行新 Agent 账户。

美股范围直接复用现有 Yahoo 快照，使用已配置的美股名单或内置大盘股候选（最多 50 只），避免套用仅支持 A 股的筛选规则；额外指定股票时直接在该名单取证。港股尚无行业候选目录，自定义条件需先指定股票。波动率字段统一为基于最近 20 日收益率的年化百分数。

新建 Agent 策略默认按自定义范围筛选。股票池为可选限制：留空时由范围条件寻找候选，填写后取交集；已确认范围的保存不依赖股票名称目录加载。仅选择“指定股票”范围或旧固定规则时需要具体股票。

配置页面按“选股配置 → 策略配置 → 运行与风控配置”排列：先确认范围，再选择 Skill / 交易指令，最后设置资金、仓位、费用与 Token 预算。
