# 报告可视化与计算绘图

聊天、个股研究、专家讨论和任务成果共用图表渲染。正文使用更清晰的标题、段落间距和可换行表格；大盘复盘直接使用已有指数涨跌幅生成对比图。原有报告仍可阅读，不会把历史文字猜测成数值。

## 使用

可以要求 Agent：“用已获取的季度收入和成本计算利润率，画折线图，列出来源和计算依据”。工具 `build_analysis_chart` 已加入默认任务工具集；已有冻结任务保留原绑定，管理员禁用的工具不会被重新启用。模型是否调用取决于任务及可用证据，不保证每段文字都有图。

支持折线、同单位分组柱状、条件关系图。图表标记真实数据、情景或示意，展示报告提供的来源、日期和单位。来源标签不是独立核验。数值图可切换系列、展开数值与计算输入、查看公式、下载 SVG。手机上图表可横向滚动。缺失值和除零留空，折线中断；横轴按输入顺序等距排列，不代表不规则时间间隔。

## 工具契约与边界

`spec` 接受 `type`、`title`、`source`、`basis`（observed/scenario/illustrative），以及可选 `asOf`、`unit`、`description`。数值图使用 `data: [{label, revenue, cost}]` 和 `series: [{name, expression: "(revenue - cost) / revenue * 100"}]`；关系图使用 `nodes` 字符串数组、`edges: [{from, to, label}]`，索引从零开始。

这是受限的可编程计算绘图工具，不是通用 Python 解释器。仅允许数字列、常量、括号和加减乘除；禁止导入、函数调用、属性访问、文件、网络和 Shell。最多 120 行、4 系列、12 输入列；关系图最多 12 节点和 20 边。沿用工具授权、取消执行和用户工作区，不增加数据库迁移或环境变量。

工具返回版本 1 的 `analysis-chart` Markdown 代码块，Agent 应原样嵌入。前端再次校验并渲染 SVG，不执行代码或原始 HTML。无效、旧版本或流式尚未完整的代码块保留为可展开原文。其他通知/导出消费端暂可能显示代码块；关系图暂不支持 SVG 下载。完整代码块保存在原有问答/报告中；模型 Token 沿用现有账本，计算工具自身不调用模型。

回滚使用上一版本镜像，保留数据库和问答记录；旧版会将新图表显示为代码块。
