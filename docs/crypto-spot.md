# 加密货币现货研究与回测

网站的“加密货币”入口（`/crypto`）提供四项功能：USDT 现货市场雷达、单币小时线研究、按历史成交额与波动率选币，以及规则策略回测和模拟持仓／成交。市场雷达、个股研究、策略选股、交易推演、持仓管理页均有入口。当前这是独立的现货模拟工作区；股票投研 Agent、股票持仓账本与股票每日模拟的契约不适用于 24/7 市场，不会把币种伪装成股票或向交易所下单。

开始使用：在网站顶部打开“加密货币”，先选交易对查看近七天走势，再在候选池勾选最多五个交易对运行选币；选择策略与 UTC 起止日期后点击“运行回测”，查看收益曲线、费用、模拟持仓和逐笔成交。

## 数据与范围

- 数据源为 Binance Spot 公开市场数据 API `https://data-api.binance.vision/api/v3`，不需要 API Key。市场雷达取 `/ticker/24hr`，小时线取 `/klines`，并逐页获取。只使用**已完成**的 UTC 小时线；第 7 列为 USDT 报价成交额，不能用基础币成交量替代。
- 默认候选池为 `BTCUSDT`、`ETHUSDT`、`BNBUSDT`、`SOLUSDT`、`XRPUSDT` 五个现货交易对，便于与参考项目复算。市场雷达另展示按当前 24 小时 USDT 成交额排序的前 20 个交易对，页面可从中组合至多五个币种。当前排名不代表历史时点的可交易币种全集；选择今天的热门币回测过去会引入事后选样偏差。
- 选币规则取过去 720 根完整小时线，按 USDT 成交额选前三，再取小时简单收益率样本标准差最高的交易对。一个策略决策只看该时点之前的已完成 K 线。页面可缩小固定池；缩小后仍按同一规则计算。
- 所有时间、起止日期按 UTC；结束日期为不包含的边界。最长 90 天评估区间，另取 720 小时预热数据。历史行情可能被供应商修订；返回的 SHA-256 指纹用于识别本次实际输入。

## 回测口径

默认初始资金 10,000 USDT，单一共享现金账本，无杠杆、无卖空；手续费单边 0.1%，滑点单边 0.05%，无股票卖出税。前一根完整小时线形成信号，下一根开盘价加减滑点成交，持仓允许小数，期末按最后一根收盘价估值，不强制平仓。手续费、滑点已进入净值，页面同时单列成本供核对。

内置三个固定规则：

1. **高量高波动轮换**：每 168 小时选币；目标变化时先卖旧币，再用交易后净值的 50% 买新币，未变化时继续持有。
2. **等权再平衡**：每 168 小时将总净值的 50% 平均分给所选交易对；先卖后买。
3. **半仓比特币**：首个执行小时用 50% 资金买入 BTC，此后持有。

结果显示收益、最大回撤、BTC 同期价格收益、成交、费滑和期末持仓。BTC 价格收益没有计入模拟交易成本，仅作参照。当前页面使用同一初始资金与固定费用进行比较；若日期、候选池、费用或样本指纹不同，不应直接比较策略收益。固定候选池仍有事后选样偏差，历史正收益不能证明未来有效。策略没有调用 LLM/JEV，也不含 QuantEvo 尚未核实的网格/JEV 规则。

## 接口与排障

`GET /api/v1/crypto/market`、`GET /api/v1/crypto/assets/{symbol}`、`POST /api/v1/crypto/screen`、`POST /api/v1/crypto/backtest`。请求只接受 USDT 现货交易对格式；无效或未上市交易对会返回数据源错误。日期未填写时默认回测最近 30 个已完成 UTC 日。数据接口超时、空白或缺小时线时返回错误，不用其他市场数据静默补齐。访问 Binance 数据域名失败时，请先核查部署环境的网络可达性；现货数据源不会回退到 Binance 永续合约行情。

当前不支持交易所账户绑定、真实买卖、永续合约、资金费率或自动每日执行。回测结果只在页面本次会话展示，刷新后需要重新运行。

参考：[Binance Spot API](https://developers.binance.com/en/docs/products/spot/rest-api)。
