# AI Stock

**AI와 함께 종목을 연구하고, 투자 아이디어를 검증하세요.**

투자 리서치 어시스턴트 · 전문가 원탁 토론 · 개별 종목 분석 · 전략 종목 선별 · 거래 시뮬레이션

[English](../README.md) · [简体中文](README_ZH.md) · [繁體中文](README_CHT.md) · [日本語](README_JA.md) · **한국어**

</div>

AI Stock은 중국 본토 A주, 홍콩 주식, 미국 주식을 위한 투자 리서치 웹 애플리케이션입니다. Agent, Skill, 시장 데이터와 도구를 연결해 분석 보고서를 저장하고, 종목을 선별하며, 모의 거래로 전략을 검토할 수 있습니다. 한국어 지원은 **인터페이스와 출력 언어**에 관한 것으로, 한국 주식시장 데이터 지원을 의미하지 않습니다.

이전 프로젝트 이름은 LLM TradeBot, InvestCrew였으며 현재 이름은 AI Stock입니다. 저장소는 [EthanAlgoX/AIStock](https://github.com/EthanAlgoX/AIStock)입니다.

## 주요 기능

| 작업 공간 | 경로 | 기능 |
| --- | --- | --- |
| 시장 레이더 | `/market-intelligence` | 시장 지표, 뉴스, 거시경제 정보 및 분석 구독 확인 |
| 투자 리서치 어시스턴트 | `/overview` | 대화형 분석, 과거 대화 확인, 전략 초안 작성 및 Skill 저장 |
| 전문가 원탁 토론 | `/expert-review` | 독립적인 전문가 관점과 진행자의 종합 의견 비교 |
| 개별 종목 분석 | `/stock-research` | 종목의 근거, 위험, 결론과 과거 보고서 확인 |
| 전략 종목 선별 | `/screening` | 전략에 따른 후보 종목, 순위와 선정 근거 확인 |
| 거래 시뮬레이션 | `/trading` | Agent와 Skill을 이용한 모의 거래 및 전략 검증 |
| 보유 종목 관리 | `/portfolio` | 보유·관심 종목의 분석, 일정과 점수 추이 확인 |

작업 기록, 예약 실행, 모델 사용량, 알림 및 기능 센터에서 각 작업 공간을 관리합니다. 사용할 수 있는 시장과 데이터 범위는 전략 및 데이터 공급자에 따라 달라집니다.

## 대화에서 전략으로

어시스턴트에서 전략 유형을 선택하면 별도의 전략 작성 대화가 열립니다. 기존 대화를 새로운 전략 대화로 가져올 수도 있습니다.

1. 종목 범위, 분석 방법, 위험 한도와 실행 방식을 설명합니다.
2. 대화를 이어 가며 초안을 수정하고 미확정 항목을 확인합니다.
3. 초안의 필수 항목을 검사한 뒤 Skill로 저장합니다.
4. 거래 전략은 기존 거래 시뮬레이션 설정 화면으로 가져와 시장, 자금과 위험 설정을 확인합니다.
5. 실제 후보 종목을 미리 보고 전략을 저장한 다음, 한 번 실행하거나 지속적인 모의 거래를 시작합니다.

필수 항목 검사는 데이터 가용성이나 수익성을 검증하는 절차가 아닙니다. Skill 저장만으로 자동 거래가 시작되지는 않습니다. 일일 분석은 장중 가격 도달 즉시 주문을 실행하는 기능과 다릅니다.

## 전문가 협업

- **파이프라인:** 진행자가 작업을 나누고 전문가가 순서에 따라 분석합니다.
- **토론:** 전문가가 독립적으로 의견을 제시한 뒤 반론과 쟁점을 검토합니다.
- **투표:** 별도의 검토 Agent가 보고서를 평가하며, 진행자가 결과와 불확실성을 정리합니다.

각 전문가는 부여된 역할과 허용된 기능 안에서 작업합니다. 저장된 의견과 토론 결과는 확인할 수 있지만, 모델 내부의 비공개 추론을 표시하는 기능은 아닙니다.

## Agent와 Skill

Agent는 목표를 이해하고 도구 사용과 작업 흐름을 조율합니다. Skill은 재사용할 수 있는 분석 방법과 지침입니다. 도구는 정해진 입력 형식에 따라 데이터를 읽거나 계산하며, MCP는 외부 시스템과 연결합니다. 사이트는 작업, 결과, 승인 및 실행 경계를 관리합니다. Agent는 위험 검사를 우회하거나 임의의 실거래 주문을 생성할 수 없습니다.

## 빠른 시작

Python 3.10 이상, Node.js 20.19–26.x, npm 10 이상이 필요합니다. 아래 명령은 macOS/Linux 기준입니다. Windows PowerShell에서는 `.venv\Scripts\Activate.ps1`로 가상 환경을 활성화하세요.

```bash
git clone https://github.com/EthanAlgoX/AIStock.git AI-Stock
cd AI-Stock
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

기존 `.env`가 있으면 덮어쓰지 말고 예제와 비교하세요. 분석을 실행하려면 모델 공급자를 설정해야 합니다. 웹 서버만 시작한다고 모델 분석이 활성화되지는 않습니다. 모델 설정은 `.env` 또는 웹 설정 페이지에서 관리할 수 있습니다.

```bash
cd apps/dsa-web
npm ci
npm run build
cd ../..
python main.py --serve-only --host 127.0.0.1 --port 8000
```

웹 화면은 <http://127.0.0.1:8000>, API 문서는 <http://127.0.0.1:8000/docs>에서 확인합니다. 포트가 사용 중이면 `--port` 값을 변경하세요.

## 한국어 사용

페이지 상단의 언어 선택에서 **한국어**를 선택하세요. 선택은 브라우저에 저장되며, 별도 선택이 없으면 영어를 사용합니다. 날짜와 숫자는 한국어 로캘로 표시됩니다.

한국어 인터페이스에서는 투자 리서치 어시스턴트의 새 요청에 한국어 답변을 명시적으로 요청합니다. 예약 분석 등 보고서의 기본 출력 언어는 설정에서 지정하거나 `.env`에 다음과 같이 설정할 수 있습니다.

```dotenv
REPORT_LANGUAGE=ko
```

언어를 바꿔도 기존 보고서, 뉴스 원문, 사용자 입력 및 종목명은 자동 번역되거나 다시 작성되지 않습니다. 모델과 외부 서비스가 반환하는 원문 오류는 그대로 표시될 수 있습니다.

## 개발 및 검증

프런트엔드 개발 서버는 `apps/dsa-web`에서 `npm run dev`로 실행합니다. 기본 주소는 <http://127.0.0.1:5173>이며 `/api`는 백엔드의 8000 포트로 전달됩니다. 백엔드 주소가 다르면 `DSA_WEB_API_PROXY_TARGET`을 설정하세요.

```bash
./scripts/ci_gate.sh
cd apps/dsa-web
npm run lint
npm run build
```
