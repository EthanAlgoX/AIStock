# 海外股票市场

[English](international-markets_EN.md)

个股研究和策略选股现在接受以下市场。**股票代码必须带交易所后缀**，不能只输入数字猜市场。页面语言与股票市场独立，例如可以用韩语研究日本股票。

| 市场 | 代码示例 | 日线来源 | 交易推演 |
| --- | --- | --- | --- |
| 台股上市 / 上柜 | `2330.TW` / `6488.TWO` | TWSE / TPEx 官方月度日线，失败后 YFinance | 支持，TWD |
| 日本 | `7203.T` | 配置后 J-Quants V2，随后 YFinance | 支持，JPY |
| 韩国 | `005930.KS` / `035720.KQ` | 配置后 KRX，随后 YFinance | 支持，KRW |
| 英国 | `HSBA.L` | YFinance | 尚未开放 |
| 加拿大 | `RY.TO` / `.V` | YFinance | 尚未开放 |
| 澳大利亚 | `BHP.AX` | YFinance | 尚未开放 |
| 印度 | `RELIANCE.NS` / `500325.BO` | YFinance | 尚未开放 |
| 德国 | `SAP.DE` / `.F` | YFinance | 尚未开放 |
| 法国 | `AIR.PA` | YFinance | 尚未开放 |

代码仅演示输入格式，不是推荐标的。原有 A 股、港股、美股入口保留。

## 快速使用

1. 打开「个股研究」，选择市场，再输入上表格式的代码。目录没有收录的后缀代码也可以直接选中；实际是否有行情由数据源校验。
2. 选择该市场的研究策略运行。新报告使用创建任务时选择的界面语言，支持简体中文、繁体中文、英语、日语、韩语。
3. 「策略选股」选择该市场的「海外量价观察」。这是**候选样本内比较**，不是全市场穷尽筛选。台股使用官方上市、上柜公司目录的前 50 个候选；日韩可使用本地股票目录的前 50 个同市场候选。其他市场需要配置股票池。
4. 台股、日股、韩股可在「交易推演」输入同市场代码后预览、保存并启动。日本、韩国的自然语言筛选必须先提供股票范围。默认交易单位分别为台股 1000 股、日本 100 股、韩国 1 股；请按具体证券、整股/零股和模拟假设调整。费用仍是用户配置的模拟参数，并非交易所最新费率。

通过环境变量指定可复现的候选范围，每个市场最多 50 个代码：

```dotenv
SCREENING_INTERNATIONAL_TICKERS={"TW":["2330.TW","6488.TWO"],"JP":["7203.T"],"KR":["005930.KS"],"GB":["HSBA.L"],"CA":["RY.TO"],"AU":["BHP.AX"],"IN":["RELIANCE.NS"],"DE":["SAP.DE"],"FR":["AIR.PA"]}
```

修改环境变量后重启应用。美股仍使用既有 `SCREENING_US_TICKERS` / 美股股票池配置。

## 官方数据凭据和边界

可在平台设置中配置密钥，或通过环境变量提供：

```dotenv
JQUANTS_API_KEY=your_key
KRX_API_KEY=your_key
```

- 台股接口无需密钥。月度日线按代码和月份缓存，当前缓存每小时刷新；公司目录缓存一小时。TPEx 的成交张数、成交仟元会分别乘以 1000，统一为股数和金额；民国日期转换为公历。
- J-Quants 使用 V2 `x-api-key`。**Free 方案延迟 12 周**，不能作为当天交易推演的及时行情。模拟引擎要求行情覆盖最新已收盘交易日，过期数据会阻止推进，不伪造当日行情。
- KRX 需要申请并获准使用对应股票、ETF 数据接口。首次历史补齐需要逐交易日请求；有时间和两年范围限制，失败按既有数据源链降级。接口缓存仅在当前进程内保留。
- 英国快照若以 GBp / GBX 报价，会换算为 GBP 后比较成交金额。快照成交金额为收盘价乘成交量的估计值，并非交易所逐笔成交额。缺失财务数据不填零，不声称已接入当地完整财报或公司行动数据库。
- 新市场新闻覆盖尚不完整；正式策略默认关闭未声明支持当地市场的新闻连接。印度研究日历使用 BSE 日历，不适用于 NSE 特殊交易时段；这些次级市场尚未开放推演。
- 静态界面随语言切换。新任务、新模型解释使用任务语言；用户输入、证券代码、既有报告原文和历史审计记录保留原样，切换语言不会改写已经保存的研究结论。

开源适配器不代表行情具有免费再分发授权。公开网站部署前应核对 [TWSE](https://openapi.twse.com.tw/)、[TPEx](https://www.tpex.org.tw/openapi/)、[J-Quants](https://jpx-jquants.com/en)、[KRX 使用条款](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO005.jsp) 与 [Yahoo 数据条款说明](https://help.yahoo.com/kb/SLN2310.html)。有 API 密钥并不自动获得公开展示或商业使用权。

## 验证与回滚

离线回归覆盖代码路由、市场隔离、官方字段、日期与单位转换、分页和推演配置。开发时在线核对了 TWSE、TPEx 月度日线；日韩付费/授权接口需配置真实凭据后验收。没有凭据时不把模拟测试当作在线验证。

回滚代码前先停止新增市场的自动任务并备份数据库；恢复旧版后不要继续运行旧版不支持的市场配置。历史报告、交易账本不删除。
