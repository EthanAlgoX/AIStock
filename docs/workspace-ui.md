# 工作台 UI 交互规范

全站以完成投研任务和阅读真实成果为中心，参考 NOFX 的暖纸色、暖炭色与朱红操作色。全站共用现有组件和主题令牌，真实状态使用独立的成功、警告和错误色。

项目品牌统一为 **AI Stock**，中英文导航、页面标题、登录与体验入口、报告和 API 展示使用同一名称；使命是“用 AI 赋能每一位股票交易者，成为自己的超级投研个体”。Web 包名为 `ai-stock-web`，本地目录为 `AI-Stock`，GitHub 仓库为 `EthanAlgoX/AIStock`。更名保留原路由、环境变量、Cookie、浏览器存储键、数据库路径、外部引擎会话前缀及 MCP 协议标识；桌面安装包身份与更新分发标识保留兼容，启动页使用新品牌。服务器继续使用 `/opt/investcrew` 及原数据挂载，更新前备份账户、配置和数据库，只替换代码与镜像。回滚相应 UI 提交并重新构建即可，无需迁移历史数据。

- 投研助理是默认打开的工作区；桌面顶部按市场雷达、投研工作台、策略选股、交易推演、资产跟踪、任务中心、工作区设置组织七个模块。投研工作台包含助理、专家圆桌和个股研究；资产包含持仓、账本与告警；工作区设置包含能力、用量和账户／平台设置。原有 URL、角色权限和业务数据归属保持兼容。
- 顶部导航提供始终可见的中英文切换入口，语言选择立即生效并持久化；投研助理、个股研究、策略选股、交易推演、专家圆桌与市场雷达共用语言状态。报告工作台、任务配置、默认方案、能力列表与执行状态使用对应语言，内置策略、Skill、专家及数据源的已登记名称和说明同步翻译。切换只影响展示，不改变能力 ID、任务合同或历史记录。
- 报告栏目、按钮、诊断与数据追溯标题跟随界面语言，不再由旧报告的生成语言决定。用户输入、自定义名称、历史报告正文及外部资讯保留原文；未知的服务端错误或自定义目录文案不做猜测性翻译。原始载荷展开仍展示保存的数据。
- 模块内页面使用顶部横向页签；窄屏可在页签内横向滚动，不挤压正文。任务中心和能力中心复用已有专属导航；设置分类也置于内容上方。手机保留助理、圆桌、个股研究、选股、交易推演五项底部导航，完整菜单提供其余入口。
- 投研助理采用完整对话画布，桌面和手机均通过顶部按钮打开历史抽屉；能力与会话上下文按需打开。输入框上方的会话设置、Skill、专家与协作方式默认紧凑展示，展开区域独立滚动；关闭不会提交任务或清空会话和选择。
- 新建投研助理对话优先把近期会话中可识别的股票与已启用的分析方法组合成快捷问题，并标注为个性化建议；无可识别历史时显示默认示例。该推荐在客户端基于已加载会话标题和当前用户消息生成，不额外调用模型或读取完整历史。
- 投研助理的专家协作只呈现运行状态和最终报告；专家圆桌通过顶部按钮打开历史抽屉，主区域直接展示已保存的逐条发言、主持人协调和总结，支持关联追问。流水线展示分工与专家成果，辩论展示质询回应，投票展示独立评审及计票。发言完成后才显示，不声称逐 token 流式生成，也不展示内部思考。
- 专家圆桌是持续群聊：消息区独立滚动，输入框常驻底部，专家与主持人分别署名，跨轮消息保留在同一会话中；完整报告通过成果卡片打开。新讨论和显式下轮调整展示成员选择，已开始轮次的冻结成员默认折叠；下轮配置不改写历史。
- 专家群聊的消息容器和专家气泡随可用工作区宽度伸展，不叠加固定最大宽度；输入区同步铺开。完整发言/报告阅读面板最大 1152px，窄屏使用屏幕宽度，长表格在消息内部横向滚动。
- 个股研究、策略选股与历史交易研究提案共用完整宽度的报告工作台：默认方案与手动配置入口在上方，历史目录通过工具栏按钮打开。选择报告后关闭抽屉，保留报告／运行 URL、状态、重试与溯源入口；配置与后台运行逻辑不变。
- 交易推演顶部固定提供模拟总览、策略管理、来源策略研究和历史研究提案。模拟账户与研究提案保持不同账本；页面切换不会保存或启动未提交的配置。
- 标题、正文、辅助标签分级；朱红色用于动作、选中状态及焦点。主要导航和操作按钮使用至少 44px 的触控范围，表格在所属区域内滚动。
- 全局提供“跳至主要内容”键盘入口，页面容器不重复嵌套 main 地标。

验证覆盖前端测试、lint、生产构建和桌面/手机页面检查；本次不更改模型、任务编排、数据源或交易权限。回滚相应前端改动并重新构建即可，不涉及数据库迁移。

本文为中文产品交互专题，当前没有对应英文文档；代码中新增全局导航辅助文案同时提供中英文。
