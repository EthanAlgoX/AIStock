# 工作台 UI 交互规范

全站以完成投研任务和阅读真实成果为中心，沿用中性背景与钴蓝操作色；不引入第二套组件库或装饰性行情。

- 投研助理是默认打开的工作区；桌面主导航以市场雷达、投研助理、专家圆桌、个股研究、策略选股、交易推演的顺序排列。市场雷达位于投研助理左侧，其余任务依次位于右侧；手机保持紧凑的五项任务导航，市场雷达在工作区菜单中；原有 URL 保持兼容。
- 顶部导航提供始终可见的中英文切换入口，语言选择立即生效并持久化；投研助理首页与全局导航使用同一语言状态。
- 宽屏辅助导航同时显示文字与图标；较窄桌面保留有标签的图标入口，手机保持五项底部导航和设置抽屉。
- 投研助理采用连续画布：左侧历史对话，右侧当前对话；专家与协作方式仍在输入框上方，不需要离开对话。
- 新建投研助理对话优先把近期会话中可识别的股票与已启用的分析方法组合成快捷问题，并标注为个性化建议；无可识别历史时显示默认示例。该推荐在客户端基于已加载会话标题和当前用户消息生成，不额外调用模型或读取完整历史。
- 投研助理的专家协作只呈现运行状态和最终报告；专家圆桌采用历史列表与中央对话区，直接展示已保存的逐条发言、主持人协调和总结，支持关联追问。流水线展示分工与专家成果，辩论展示质询回应，投票展示独立评审及计票。发言完成后才显示，不声称逐 token 流式生成，也不展示内部思考。
- 专家圆桌是持续群聊：消息区独立滚动，输入框常驻底部，专家与主持人分别署名，跨轮消息保留在同一会话中；完整报告通过成果卡片打开。下轮配置可显式调整，历史配置不变。
- 专家群聊的消息容器和专家气泡随可用工作区宽度伸展，不叠加固定最大宽度；输入区同步铺开。完整发言/报告阅读面板最大 1152px，窄屏使用屏幕宽度，长表格在消息内部横向滚动。
- 个股研究、策略选股、交易推演共用报告工作台：默认方案与手动配置入口在上方，历史目录在左，独立阅读区在右。手机上下排列，目录可折叠。
- 报告历史目录固定在全局页头下方，避免滚动时被导航遮挡。配置与后台运行逻辑不变。
- 标题、正文、辅助标签分级；蓝色优先用于动作、选中状态及焦点。标准操作按钮至少 44px 高。
- 全局提供“跳至主要内容”键盘入口，页面容器不重复嵌套 main 地标。

验证覆盖前端测试、lint、生产构建和桌面/手机页面检查；本次不更改模型、任务编排、数据源或交易权限。回滚相应前端改动并重新构建即可，不涉及数据库迁移。

本文为中文产品交互专题，当前没有对应英文文档；代码中新增全局导航辅助文案同时提供中英文。
